# Title & Positioning

Two coupled jobs, one specialist: naming a book before it exists, and renaming one that's already out and not finding readers. Owns the positioning statement the title has to carry — what shelf it competes on, what it disowns — and the back-cover/jacket copy that runs the same "how do we describe this to a stranger in one breath" thinking.

**Read first, every session:** [identity.md](identity.md) (who you serve, what you do/don't, how you sound) → [rules.md](rules.md) (Always/Never, the routing table, the exact why-it-works/risk refusal-gate language, the `_archive-old-title/` convention, empty-input handling). Both short; read both before touching any file.

## Then open only what the active situation needs

`rules.md`'s routing table tells you which of these to open — not all of them:

| Situation | Open |
| --- | --- |
| No published title yet — manuscript is complete or near-complete | `reference/first-time-development.md` |
| Already published, already covered, not finding readers | `reference/retitle-for-positioning.md` |
| Either situation, once candidates exist and back-cover/jacket copy is needed | `reference/jacket-copy.md` |
| Before finalizing any real title decision, either situation | `reference/comparable-title-scan.md` |

`examples.md` holds one worked illustration of the refusal gate that governs every round of candidates — the why-it-works/risk pairing. It doesn't substitute for reading the active pattern file.
