# Jacket copy

Back-cover/jacket copy is a closely coupled output of both title patterns, not a separate job — the same "how do we describe this to a stranger in one breath" thinking that produces a good title produces good jacket copy. Read directly from `GabeYoga-HQ/Detox Book/design/cover/BACK-COVER-COPY-2026-07-24.md`, a real, dated copy-of-record file.

## Version every copy file, dated

A copy change is a new dated file (e.g. `BACK-COVER-COPY-2026-07-24.md`), not a silent overwrite of whatever existed before. This is the same iteration discipline the manuscript outline itself uses — a version is a record, not a draft that erases the last one. When jacket copy changes, write a new dated file and note what changed and why, the way the real trail's own file states its provenance in its first two lines ("Operator sent the publisher a revised bio + a verbatim Chapter One excerpt for the back panel. This file is the copy of record — check the returning proof against it, character for character.").

## What a jacket-copy file actually contains

From the real trail, a complete jacket-copy file carries:

- **A bio**, scoped to what the author can actually claim. The real trail's own locked constraint: authority = personal practice + direct observation + relevant training + real conversations + the author's own body/experience as the laboratory. **Never imply a credential or a supervised-outcome claim the author can't back** — the real trail's own rule: no client counts, no implied program-supervision the author didn't actually do. If a proof comes back with a number of people helped that wasn't sourced from the author, that's a reject.
- **An excerpt**, verbatim from the manuscript, sourced and cited (chapter + line range). If the excerpt carries load-bearing formatting (italics on a specific phrase, a specific line break), preserve it — the real trail flagged italics on one phrase as load-bearing and specified it explicitly rather than leaving it to whoever typesets the proof.
- **A typography/setting ask**, if the excerpt needs to visually read as "from the book" rather than blend into marketing copy — the real trail's own ask: "must look like it came off a page — book serif, ruled or indented, small attribution line." State this explicitly; a proof that sets the excerpt in the same face as the rest of the blurb loses the effect.
- **A resolved decision list** for anything genuinely contested (e.g., which of two covers runs where, whether there are one or two subtitles across editions) — state the resolution and who made the call, and mark it as resolved so it isn't re-litigated on the next proof pass.

## The belongs-to-this-book check — mandatory, not optional

**A real incident already happened on this shelf.** A publisher's comp carried a different book's back-cover text verbatim — *Hold The Room*'s back cover, word for word, including its own cue-reference QR code and category line, on a *Detox Book* proof. It wasn't caught by assuming the comp was correct; it was caught because someone checked the returning proof character-for-character against the copy of record.

**Never assume a publisher comp, a template, or a prior proof is pre-validated for this book.** Every time a proof comes back, check it against the dated copy-of-record file directly — bio text, excerpt text, category line, any QR or footer URL, the barcode zone. A wrong-book carryover is invisible on a skim; it only surfaces on a direct, character-for-character comparison.

## Worked reference — what a real check catches

The real trail's own check list on a returning proof: no fabricated client numbers · the author's actual credential spelled out in full, not abbreviated · the excerpt unaltered, including its load-bearing italics · the category line matches the book actually being sold, not whatever the template shipped with · the footer URL points at this book's own site, not a sibling book's or the author's general brand site · a barcode zone is reserved even if the real barcode isn't final yet. None of these are hypothetical — each one traces to a specific real correction made on a specific real proof.
